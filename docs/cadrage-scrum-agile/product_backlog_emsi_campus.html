Definition of Done (DoD) Strict
  • Code conforme aux conventions Clean Code & vérifié par Pair Programming (XP).
  • Tests unitaires & d'intégration passants (Couverture ≥ 75% via JUnit / Vitest).
  • Critères Gherkin (Given/When/Then) validés par des tests d'acceptation automatisés.
